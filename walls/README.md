# Wallpapers

`cityview.webp`, `sunset.png`, `horizon.png`, and `night.png` are copied from the current machine's `~/Pictures/`. Current Plasma desktop and lock-screen configs reference cityview. The X11 display helper expects horizon at `~/.config/wallpaper/horizon.png`; choose your own destination and adapt references.

These are original captured files, with hashes in `../docs/sources.json`. Wallpaper authors/license information was not available in the selected files.

`mountain.png` is the Niri wallpaper snapshot; Niri's startup command expects it at `~/Pictures/mountain.png`. The source snapshot license is retained in `../niri/LICENSE`, but wallpaper-specific authorship/rights were not independently established.
